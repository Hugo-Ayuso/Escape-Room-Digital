# Requisitos del proyecto

## Descripción
Escape Room Digital es un videojuego de aventuras en el que los jugadores exploran habitaciones,
encuentran pistas, resuelven acertijos y desbloquean nuevas zonas antes de que termine el tiempo.

## Requisitos funcionales
- El jugador puede explorar las habitaciones.
- El jugador puede recoger y consultar pistas.
- El juego incluye acertijos que deben resolverse.
- Resolver los acertijos permite desbloquear nuevas zonas.
- Existe un temporizador con límite de tiempo.
- El juego muestra si el jugador gana o pierde.

## Requisitos no funcionales
- Interfaz clara y fácil de utilizar.
- Código organizado y mantenible.
- Los recursos multimedia se almacenan en `assets/`.
- El proyecto debe poder ejecutarse desde Python 3.10 o superior.
