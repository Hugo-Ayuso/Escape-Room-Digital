# Escape Room Digital

Videojuego de aventuras en el que los jugadores exploran habitaciones, encuentran pistas,
resuelven acertijos y desbloquean nuevas zonas antes de que termine el tiempo.

## Estructura

- `.github/`: plantillas de incidencias.
- `docs/`: requisitos y manual de instalación.
- `src/`: código fuente del juego.
- `tests/`: pruebas automatizadas.
- `assets/images/`: imágenes y gráficos.
- `assets/audio/`: música y efectos de sonido.
- `assets/data/`: datos y configuración.

## Ejecutar el prototipo

Necesitas Python 3.10 o superior. Desde la raíz del proyecto:

```bash
python src/main.py
```

## Abrir en Visual Studio Code

1. Descomprime la carpeta `escape-room-digital`.
2. En Visual Studio Code, selecciona **Archivo > Abrir carpeta...**.
3. Selecciona `escape-room-digital`.
4. Abre el terminal integrado y ejecuta `python src/main.py`.
